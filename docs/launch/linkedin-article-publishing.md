# Publishing this article on LinkedIn

## Files

- Article source: `illustrated-introduction.md`.
- Formatted browser copy: `illustrated-introduction.html`.

- Inline images, in order: `../../images/01-guided-setup.png`, `../../images/02-knowledge-files.png`, `../../images/03-generated-app.png`.

## Transfer to the article editor

1. On LinkedIn’s desktop website, choose **Write article**.
2. Put **From Custom GPT to Standalone AI App: Why I Built AI App Studio** in the article’s Title field.
3. Open `illustrated-introduction.html` in your browser. Copy the rendered article body, beginning with “Your team’s most useful Custom GPT,” into LinkedIn’s **Write here** area. Use the rendered text rather than pasting Markdown syntax or HTML source. Check heading styles, bold text, lists, the quotation, and hyperlinks after pasting; adjust them with the editor’s toolbar if needed.
4. Add each screenshot through the editor’s Media control at its corresponding paragraph. Upload the corresponding PNG files from the repository’s images folder; local Markdown image references are not upload instructions. If pasting left an empty or broken image, replace it with the uploaded screenshot. Use the caption immediately below each image in the source. The Markdown image descriptions provide suggested alt text.
5. If using the existing illustration as the article cover, upload `../../images/hero-image.png` above the title and check its crop. It was created for a wide feed post. LinkedIn’s current article-image guidance says covers are cropped to 16:9, so confirm that the headline and all three stages remain visible. The article does not depend on including this cover illustration in its body.
6. Use LinkedIn’s Preview before publishing. Confirm all three screenshots, their captions, the official OpenAI source links, the Sites link, and the GitHub link.

The article file contains publishable copy only. These transfer instructions are separate so they are not accidentally included in the article.

## Formatting choices

The article uses a single title, section headings, short paragraphs, bold emphasis, one blockquote, simple lists, descriptive hyperlinks, and inline images with captions. It avoids tables, nested lists, code blocks, footnotes, and custom layout markup.
